# Hadar Alpha Arena v3 — Game Premium

A multi-asset decision engine for the user's swing-trading workflow. Core analysis is Daily / 12H / 4H, with 1H candle direction only. No 15-minute layer.

Highlights: VIX regime filter for stocks, 4H + 12H RSI divergence, BOS/CHoCH, relevant-impulse Fibonacci 0.50–0.618, SuperTrend, Wyckoff/range location, volume, liquidity sweeps, support/resistance, flags/wedges, confluence scoring and a Game Premium dashboard.

This is an analytical decision-support tool, not a guarantee of future performance and not automatic trade execution.
